\title{Readme file for data and programs accompanying McKay and Wieland (2021), ``Lumpy Durable Consumption Demand and the Limited Ammunition of Monetary Policy.''}
\date{\today}

\maketitle

The enclosed data and programs reproduce the tables and figures in
the paper. All data and programs are provided without warranty. 

\begin{enumerate}
\item To recreate all the figures in the paper, including the appendix figure run the python script rundirectory.py.
\begin{itemize}
	\item On line 6 of the rundirectory.py you need to enter the path of the replication directory.
\end{itemize}
\item Running this script takes around 2 days on an 8-core iMac (2020 model). Most of this time is spent estimating the model and computing the partial equilibrium Jacobians. The programs were executed using:
\begin{itemize}
	\item Matlab 2020a
	\begin{itemize}
		\item Matlab needs to be executable from the command line.
	\end{itemize}
	\item Python 3.8.8 (Anaconda distribution)
\end{itemize}
\item The script runs the following files in sequence:
\begin{enumerate}
	\item IRFs/main.m: Creates Figures 2, 3, and Appendix Figure A.3. All subroutines are included in the Folder IRFs. The programs call raw data files from the Data folder.
\begin{itemize}
	\item Appendix Figure A.2 can be obtained by changing the parameters in the Specification section at the beginning of main.m.
\end{itemize}
	\item Model/figure1.m: Creates Figure 1 and Appendix Figure A.1. This file runs the estimation of the model which takes around one day to complete.
	\item Model/solvesteadystate.m: solves for the steady state of the model.
	\item Model/computejacobians.m: solves for the partial equilibrium Jacobians of the model. This code will run for around a day.
	\item Model/constructirfs.m: solves for the general equilibrium Jacobians of the model.
	\item Model/figure45.m: Creates Figures 4 and 5.
	\item Model/figure6.m: Creates Figure 6. 
	\item Run Model/figure7.m: Creates Figure 7.  
	\item Model/figure811.m.: Creates Figures 8-11 and Appendix Figure A.4.  
\end{enumerate}
\item All figures are stored in the Figure folder of the base directory in png format.
\end{enumerate}
